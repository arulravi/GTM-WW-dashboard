# GTM WW — Opex & HC Outlook Dashboard

A live, refreshable dashboard that rebuilds the **Opex / Headcount Outlook walk**
directly from the finance SQL server — replacing the hand-linked Excel workbook
(whose historical cells had gone to `#REF!`).

## Run it as an app

**Double-click the "Opex & HC Outlook" icon** on your Desktop (also in the Start
menu). It opens as a **real native app window** — no console, no browser tabs, no
address bar. Inside the app, the **🔄 Refresh** button re-pulls live data from SQL
whenever you want. **Close the window to quit** (nothing lingers). First launch
pulls data automatically.

- The app is `app_native.py` (native window via pywebview / Windows WebView2),
  launched with `pythonw` so there's no console window.
- `Opex HC Outlook.bat` does the same from a file double-click.
- `Create Desktop Shortcut.vbs` re-creates the Desktop/Start-menu shortcut with
  the custom icon (e.g. if you move the folder).

> Server-free fallback (no live refresh): `Open Dashboard (App).vbs` opens the
> last-saved data in an Edge/Chrome app window.

## …or open it as a web link (in your browser)

Prefer a browser tab / bookmark instead of the native window?

1. Double-click **`Start Web App.bat`** — starts the web server (small window,
   keep it open) and opens your browser to the app.
2. The link is **http://localhost:8770/** — **bookmark it**. A bookmark
   **"Opex & HC Outlook (Web)"** is already on your Desktop and Start menu.
3. The 🔄 Refresh button works the same way (live SQL). Close the little server
   window to stop.

The link works while the web server is running. To have it always available,
run `Start Web App.bat` at login (or ask to enable auto-start).

## The executive dashboard — `dashboard.html`
A polished, single-page executive view (the leadership-ready one).

- **One tab per org** across the top: *AMER CXO + Ecosystem* (default, kept as
  its own combo summary), then *AMER CXO*, *Ecosystem*, *AMER C&P*, *EMEA*,
  *Global Mgmt*, *Sales Ops*, and **GTM WW** — a combined summary across all
  six L3s.
- Each org tab has **Opex Overview** and **Headcount** sub-tabs.
- Header selectors: **Quarter**, **Current** version, **vs-Target** version,
  plus an optional **Drill L4** to go deeper inside the selected org.
- Compact KPI cards (vs-QRF / vs-Plan / QoQ deltas), an auto **Variance Story**,
  **Risks & Opportunities**, the Opex walk with **inline editable commentary at
  the end of each row**, and a Headcount view (hires / terms / net moves / open
  reqs). Dark & light themes. Commentary is saved per org-tab.

- **One click:** `Refresh & Open Dashboard.bat` — pulls fresh SQL data then opens it.
- **Just view:** `Open Dashboard.bat` (uses the last refreshed data).
- Data lives in `data.js`, regenerated by `refresh.py` (see below).

### Streamlit app (alternate / exploratory) — `app.py`
The original interactive version. `Run Dashboard.bat` or `python -m streamlit run app.py`.

## Why this exists
The weekly Outlook files are large workbooks with fragile cross-links. This app
pulls the same numbers straight from the source views, so a "refresh" is one
click and the numbers always tie to the system of record. **Refreshing is always
manual — you run it when you want it.**

## Data source
- **Server:** `FinSys.corp.adobe.com,1433`  (Windows / AD auth — no password stored)
- **Database:** `finance_systems`
- **Views:**
  - Opex → `dbo.vw_Expense_Final_LDAP_Filtered`
  - Headcount → `dbo.vw_Headcount_Final_LDAP_Filtered`

## Reporting layout
The report **auto-tracks the current fiscal quarter** (read from the view's
`Curr Fiscal Qtr/Year` marker), so it rolls to the new quarter automatically —
no code or config change each quarter. The columns are:

> **prior Actuals quarters → Quarter-to-date Actuals → FY## Plan → Q# QRF → Forecast**

The **Forecast** (the live rolling forecast for the current quarter) is the
headline scenario. There are no weekly WK OL columns.

## How the model works (validated against the WK10 workbook)
- **Opex** = `SUM(Value USD)` grouped by `Major Cost Element Grp Desc`,
  **excluding** the `Commission` cost-element group (sales commissions are
  reported separately). This reconciled the WK10 total to 142.4M vs the
  workbook's 142.1M — every line item ties out within snapshot drift.
- **Scenario columns** come from the `Version` field: `Actuals`, `FY## Plan`,
  `FY## Q# QRF`, and `Forecast`. Transfer-adjusted (`TSFR ADJ`) variants are
  preferred where they exist.
- **Headcount** = `SUM(Headcount)` per fiscal period; the quarter figure uses a
  selectable convention (default *current actual month*, which matched the
  workbook's 2038 for WK10). HC is not shown for the QTD-Actuals column (the
  `Actuals` HC version double-counts and HC is point-in-time).
- **Risks & Opportunities** are auto-generated from the Forecast-vs-Plan
  movement (increase on a cost line = risk, decrease = opportunity) and are
  fully editable.
- Adobe's **Dec–Nov fiscal calendar** is taken straight from the views'
  `Fiscal Year / Qtr / Period` fields — nothing is recomputed.

## Using it
1. **Segment** — one or more `CCH Lvl 3` hierarchies (defaults to AMER CXO +
   Global Ecosystem; the dashboard's scope now also covers AMER C&P, EMEA,
   Global Mgmt, and Sales Ops, combined in the GTM WW tab; any segment works —
   LATAM, Enterprise, TPS, etc.).
2. The **reporting period defaults to the live current quarter**; open the
   *Reporting period* expander in the sidebar to look at a past quarter.
3. Tick which **columns** to show (QTD Actuals / Plan / QRF / Forecast).
4. **💰 Opex Walk** — the P&L walk plus an **editable Commentary** column
   (saved per quarter). **🎯 Risks & Opportunities** — auto-suggested from the
   numbers and editable.
5. **⬇️ Export & Snapshot** — download Excel / PDF / CSV, or **📸 Save a
   finalized snapshot** (a timestamped Excel that won't change when live data
   moves).
6. **🔄 Refresh data from SQL** (sidebar) is the *only* thing that re-pulls —
   refreshing stays entirely in your control.

## Files
| File | Purpose |
|------|---------|
| `app.py` | Streamlit UI |
| `config.py` | Connection, scope, cost-element order, version rules, storage dirs |
| `db.py` | Parameterised SQL queries (incl. current-quarter marker) |
| `fiscal.py` | Fiscal helpers + Version/scenario resolution |
| `transform.py` | Builds the walk, HC, per-head, variances, risks & opportunities |
| `export.py` | Excel / PDF / CSV generation |
| `store.py` | Saves editable commentary + finalized snapshots locally |
| `commentary/` | Saved commentary JSON (per segment-set + quarter) |
| `snapshots/` | Finalized frozen Excel snapshots |

## Extending
- **New segments** already work via the sidebar. To change the default set, edit
  `DEFAULT_SEGMENTS` in `config.py`.
- **Risks & Opportunities** are currently rule-based (largest Forecast-vs-Plan
  movements). They can be upgraded to an LLM-written narrative if an API key is
  configured.
